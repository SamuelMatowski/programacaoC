# Lista de Exercícios - Pseudocódigo convertido para C

Conversão da lista "Estruturas sequenciais e condicionais" (3 exercícios básicos,
5 médios e 2 avançados) para a linguagem C.

| Arquivo | Exercício |
|---|---|
| exercicio01.c | Soma e comparação |
| exercicio02.c | Média e situação do aluno |
| exercicio03.c | Número par ou ímpar |
| exercicio04.c | Desconto em uma compra |
| exercicio05.c | Reajuste salarial |
| exercicio06.c | Consumo de combustível |
| exercicio07.c | Classificação por idade |
| exercicio08.c | Maior entre três valores |
| exercicio09.c | Cálculo de tarifa de energia |
| exercicio10.c | Avaliação de aprovação completa |

## Compilar e executar

```bash
gcc exercicioXX.c -o exercicioXX
./exercicioXX
```
